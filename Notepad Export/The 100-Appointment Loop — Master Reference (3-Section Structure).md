# The 100-Appointment Loop — Master Reference (3-Section Structure)

Same 172 deliverables, same 19 phases, same numbering as the source list — reorganized into three top-level sections by **function in the loop**, not by chronology alone. Nothing removed. Where the four decisions we already locked (content menu, tool-suite tier, voice AI, retainer pricing) change an item's status, it's bracket-annotated inline rather than deleted, so this stays a complete reference.

## Why these three, and these names

The 19 phases actually do one of three jobs:

1. Things that have to exist **before** the machine can run, and stay true underneath it the whole time (positioning, ICP, domain/email infra, compliance).
2. The machine **itself** — everything that fans out in parallel and runs continuously to turn attention into booked, qualified meetings (content, tools, funnel, leads, signals, outreach, social, chatbot, pre-call research, booking).
3. The layer that makes the machine's output **visible, provable, and durable** — the dashboard, the reporting, and what happens after month one (dashboard, guarantee/target tracking, retainer ops, expansion).

That gives **Foundation → The Acquisition Engine → Command Center** — reusing "Command Center" since Phase 0 already named it as a branded component; no reason to invent a second name for the same thing.
